Roundcube Webmail Skin "Elastic Compact"
========================================

A child skin of Roundcube's "Elastic" skin with a denser desktop layout. See the README at the top of this
repository for installation and building.

CREDITS
-------

Based on the "Elastic" skin by Aleksander Machniak and The Roundcube Dev Team
(https://github.com/roundcube/roundcubemail/tree/master/skins/elastic). The compiled `styles/styles.min.css`
contains Elastic's styles together with the changes in `styles/styles.less`.
